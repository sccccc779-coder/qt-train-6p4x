第 3 节 · 一句话价值主张

我们卖什么：设备 + 环境，不是软件

把 Android 跑在云端机房，客户远程操作一台「手机」。这一句是全部产品话术的根。

一句话版本（背下来） 「我们卖的是设备 + 环境，不是软件。」
硬件底座是 ARM 板卡，一张板卡切成多个「窗口」，一个窗口 = 一台独立云手机。同一张板卡可变开窗数——灵活性的来源。

对外能讲清楚的四项关键能力

设备环境隔离
一台窗口 = 一套独立环境

每台云手机是独立环境，互不干扰——「一机一号」的前提。

独立 IP
自有 IP 资源，可单卖也可打包

自有 IP（QTProxy）可单独卖、也可随设备打包——打包时绑得更稳。

批量群控 / 同步器
一台电脑管一批手机

直接对应客户的「人力成本」痛点，可视化强，最适合做内容素材。

应用与安全认证
Google Play / SafetyNet / Widevine L1 三项

海外场景的硬门槛：跑海外 App 时，这三项认证是能不能正常用的前提。

我们不做什么（主动讲，避免错位期待）

不做怎么对外说
不碰内容生产只做底层「设备与环境」，内容与运营由客户自己做
不养号不提供账号代养、批量注册类服务
不做代运营上层服务让第三方入驻，我们不抢客户的客户

四条差异化（对代理讲的核心）

  1. 代理自由定价——不设最低零售价、不没收码。
  2. 下级无连坐——下级出问题不牵连上级。
  3. 透明自助白标——注册即解锁基础版，不走商务审批。
  4. 一个后台一个账单——设备 + IP 打包，不用两头对账。
不打的仗：不比硬件参数 我们的硬件参数弱于主要对手——中性事实，不用回避，也不用美化。所以：任何场合都不比内存、不比核数。我们比的是模式：谁能让你长期赚。承认短板比掩饰更有说服力，尤其是对方已经查过参数的时候。
第 4 节 · 三条标准答法

价格异议怎么破

异议只有三种，答案也固定。照着说，不要即兴发挥。

对 SaaS / 终端客户（只讲单窗口成本，不提板卡）：

「便宜的我信。但你要算的是单窗口成本，不是单机月费——单价便宜的，窗口掉线、易封、换 IP 麻烦，实际更贵。你要算的是『能用的窗口，一个月花多少』。」

对 PaaS / 渠道 / 板卡租赁客户（他们才关心一张卡开几个窗）：

「你拿现在的实际开窗数算一下单窗成本——我们一张卡能开 3 到 6 个窗，别人写死 4 个，窗数越灵活，你的单窗成本越低。我给你算笔账。」

关键：先判断对面是哪一层人，再选上面其中一条。两个口径混着说，等于把自己的底牌摊开。

「可以谈。但我更想知道——你手上有没有一个客户可以先给他跑一个月？你来跟，跑通了咱们再谈分成。」

为什么这样回：把「要不要免费东西」换成「你愿不愿意押上自己的客户关系」。愿意押注的才是真渠道。

「对，这项我们确实不如。所以我们的定价和代理政策是另一套逻辑——我们不跟你比谁的核多，我们比谁能让你赚得多。」

不要辩解参数。承认短板 + 立刻转到代理政策与长期收益，比硬抬参数有效得多。

谈价格之前先确认三件事 ① 对面是 SaaS 层还是 PaaS / 渠道层（决定用哪套口径）；② 单窗口成本算得出来吗（用他自己的业务量算）；③ 对外口径是否统一。三条缺一条，就先谈需求，别谈价格。

第 6 节 · 量化

漏斗与盯数：每天只盯四个数

盯数不是为了考核，是为了知道卡在哪一环。看不清卡点，努力就是碰运气。

两个漏斗，卡点各在哪

漏斗链路最漏的一环
A ｜ 直销 SaaS私信 → 回复 → 有效沟通 → 加微 → 成交私信 → 回复（实测约 4%，目标 10–15%）
B ｜ 招代理 / 渠道触达渠道 → 回复 → 有效沟通 → 签约触达 → 回复（实测约 10%，目标 20%）
漏了怎么办 先把「→ 回复」这一跳做上去，后面几环才会放大。在低回复率的水位上加大私信量，只是往漏水的桶里加水。

日打卡：四个数，20:00 前交

字段口径
私信数当天发出并计入漏斗的私信条数（目标 20）
回复对方有实质回应，不是表情、不是「嗯」
有效沟通聊到设备 / 环境 / 多账号的具体问题
加微加到微信、进入可长期跟进池
成交单独标记。「一单」= 1 次成交，不论大小。

另需填 私信→回复 一列（= 回复 ÷ 私信数）。没交 = 记 0。

怎么盯 每天 20:00 前把四个数填进漏斗表，团队与每人各一份；周会只讲数字，不讲感觉。一句话说清「卡在哪一环、下一步改哪个动作」。
第 7 节 · 开场

开场话术：三种场景，三种打法

开场决定 90% 的结果。错误开场，是回复率只有 4% 的直接原因。

❌ 错误开场 「你好，我们是做云手机的，需要了解一下吗？」
→ 对方已经收到过 100 条一模一样的话。回复率 4% 就是这么来的。
›
群内开场
先给价值，不推销
「问个技术问题——你们现在多账号是分设备隔离，还是靠指纹浏览器做环境隔离？我们最近在测不同方案对账号关联的影响，想找几个真实场景对照一下。」

为什么有效：它把「买不买」换成了「你现在的方案是什么」——对方回答的过程，就是自我暴露痛点的过程。

›
私信开场
一句话说清身份 + 能给他什么
「看到你在群里问 XX 的问题。我们是做云手机底层的（不是卖账号的），这块正好有实测数据，发你参考。」

硬要求：后半句必须真的给东西。给不出来的别发——发两次空话，这个人就废了。

›
评论开场
给答案，不给广告
对方问「XX 会不会封号」→ 答「看平台判的是设备指纹还是行为。设备层能改的只有一部分，行为层改不了。」

永远不要在评论里留联系方式。用有价值的内容让人主动私信你。

三条必问（问出来了，才知道该不该继续）

必问 1 · 筛质量
「你现在主要收入是靠新客户还是老客户？」→答老客户的是好客户 / 好渠道（他懂留存生意）；答新客户的多是倒货的。
必问 2 · 探设备
「现在大概多少台设备在跑？主要用真机还是云机？」→摸他的规模与现用方案，也判断他离成交多远。
必问 3 · 探决策权
「这块是你自己定还是团队一起看？」→决定是继续深聊，还是先要资料、走团队流程。
三句话之后要做什么 问完三条必问，只有两种结论：① 命中画像 → 进入有效沟通，约下一步；② 不命中 → 礼貌收尾，不要硬推。
判断要在十条消息之内做完，别把时间花在不会买的人身上。
第 8 节 · 对比

竞品铁律：不比参数，比政策

只比一件事：代理政策。这是对手的软肋，也是我们唯一稳赢的战场。

铁律 不要比内存、不比核数。
要比的是代理政策——不设最低零售价、不没收码、下级不连坐。

我们怎么说

标准答法 「我们的代理政策很简单——不设最低零售价、不没收码、下级不连坐。定价你自己定，白标注册即解锁。原因也实在：我们靠续费赚钱，不靠罚代理赚钱。」

行业公开做法（中性事实，只说事实）

下面是行业里公开存在的做法，只做事实对照——不作评价、不作推荐、不指名贬损。

行业公开做法
严格管控代理零售价，违规没收激活码（第 1 次扣 10%、第 2 次扣 20%）
我们的差异
不控价、不没收码；低于最低零售价门槛的窗口只是不参与返利计算——我们不惩罚，只是不补贴
行业公开做法
下级违规 → 上级连坐封码
我们的差异
下级不连坐
行业公开做法
代理拿货的利润空间被压得极薄
我们的差异
代理的利润结构比我们厚，这是有意的设计
行业公开做法
白标要走商务审批，条款不透明
我们的差异
透明自助白标，注册即解锁基础版
行业公开做法
行业公开返佣区间各家口径不同，部分厂商未公布具体比例
我们的差异
我们不讲虚的：政策条款签协议前就能看到全部
被追问参数时的三段式 ① 承认：「对，这项我们确实不如。」
② 转移：「所以我们的定价和代理政策是另一套逻辑——不比谁核多，比谁能让你赚得多。」
③ 落地：「我按你现在的量算一下单窗口成本和月度收益，你看数字就行。」
全程不评价任何具体厂商，不引用未公开信息。
一条容易犯的错 对 SaaS 客户讲代理政策细节（返利、门槛）——他听不懂也不关心。代理政策只对「要拿货去卖的人」讲；对终端客户，只讲单窗口成本与稳定性。
第 9 节 · 渠道

渠道两条轨道：A 白标型 + B 传统经销

B 轨通常最终流向 A 轨。理解这条路径，你才知道该把力气花在哪。

点击任一节点查看这条轨道上代理赚什么、我们要求什么。

从触达到深绑：六个台阶

点击上方任一台阶查看这一步的判断标准和常见卡点。
为什么要按台阶走 第一性原理：绑定 ≠ 合同条款，绑定 = 他离场时会损失什么。只损失差价的人，谁价格低就跟谁走。
所以顺序是：低门槛先进来（返利型 / 小量试货）→ 再往深绑（续费分成、客户触点、白标、下级网络）。
⚠️ 反作用力：早期代理只有几家时，条款过硬会吓跑第一批——正确打法是「低门槛进、越做越深绑」，不是全员上锁链。
第 10 节 · 代理靠什么赚钱

代理五条利润腿

招募代理时按需披露。五条腿是渠道动力的全部来源——只讲价差，招不到人。

① 板卡价差
拿货价与零售价之间的差价

A 轨代理的即时收益。定价权在他手上，我们不控价。

② 季度返利
按采购量分档，比例待定、暂不写死

做出量之后才拿得到的那一层。返利 ≠ 价格管控：低于门槛的窗口不参与返利计算。

③ 白标权益
用自己品牌对外（注册即解锁基础版）

白标是绑定工具，不是赠品——品牌长在我们的机房里，带走客户也带不走品牌资产。

④ 下级代理抽成
下级出货，上级每月抽成

这是长期的那条腿：把一部分收入挂到「下级网络」上，让上级有动力发展与管理下级。

⑤ IP
自有 IP（QTProxy）——可单独卖，也可随设备打包

可单独卖，也可打包；打包时IP 跟着设备一起产生续费，也是「一个后台一个账单」的基础。

+ 续费分成
客户每月续费，代理每月都有份

把利润从「一次性出货差价」挪到「客户续费」上，代理就从重出货变成重留存。这是当前最重要的绑定方向。

话术落点（可以原话讲给代理） 「我们的利润结构就是这么设计的：我们要的是规模和续费，不是每单多赚一点。」
「别人给你的是一台机器的差价，我们给你的是一个能持续收钱的客户关系。」
注意边界 五条腿里，返利档位、白标档位、下级抽成比例属于政策条款——对外只能讲已经成文、口径统一的版本。政策未定稿前，用「价差 + 返利 + 白标 + 下级抽成 + IP」的结构讲，不要报具体档位数字。
第 11 节 · 政策

代理门槛与返利

只讲逻辑框架：按月度拿货量分档，量越大权益越深。具体门槛与比例待定，对外不报数字。

维度递进方向
季度返利比例逐档提高
白标能力改名 + Logo → + 启动页 + 独立域名 → + 包名 + 支付 + 完整白标
API 权限高等级开放
下级抽成最高档才开

分档逻辑与权益递进见《云手机业务背景》5.2。板卡口径只用于渠道 / PaaS 层——对终端客户不提这一栏。

✅ 口径已定：分级只讲逻辑，不报数字 按「月度拿货量」分档（银 → 金 → 钻石），量越大、权益越深——返利比例 / 白标能力 / API 权限 / 下级抽成，四项逐档递进。
具体门槛与比例待定，对外一律只说「分档逻辑」。

返利 ≠ 价格管控

机制 代理可自由定价；低于「最低零售价门槛」的窗口不参与返利计算。
对外话术：「不限制任何代理的零售定价；返利机制只奖励与我们一起维护健康市场的伙伴。」
与「违规没收激活码」的本质区别：我们不惩罚，只是不补贴。
门槛说明要主动给，不要等对方问 招募代理时把分档逻辑讲清楚（讲「量越大权益越深」，不是报数字）。对方问价你不说，他默认你有隐藏条件；主动给，才是「条款透明」的落地。

两种绑定抓手（讲给谁听）

对公司
代理离场时会损失什么：续费分成（一走即清零）· 客户触点（账单 / 后台入口直达我方）· 白标品牌 · 下级网络 · 合约（最弱，只对已互信渠道用）。
对代理
「你出的货，客户每月续费你每月都有份。」——把这句话讲透，比讲返利百分比有效。

术语速查

开会、谈客户时听到不懂的词，回来查这里。

窗口
一台独立云手机。用户层唯一对外使用的计费单位。
板卡
ARM 硬件底座，一张板卡切成多个窗口。对 SaaS 客户与终端用户一个字不提。
单窗口成本
能用的窗口一个月花多少。对 SaaS 客户谈价的唯一口径。
白标
代理用自己品牌对外（改名、Logo、启动页、独立域名、包名、支付）。对我们是绑定工具。
贴牌
渠道用自己品牌包装我们的平台对外销售，属 A 轨。
五条腿
代理的五个利润来源：板卡价差 · 季度返利 · 白标权益 · 下级抽成 · IP。另加续费分成。
返利
按采购量阶梯给的季度返利（银 / 金 / 钻石档）。返利 ≠ 控价：不惩罚，只是不补贴。
控价 / 最低零售价
限制代理的零售定价。我们不控价；只设「最低零售价门槛」，低于门槛不参与返利计算。
没收码 / 连坐
行业里的两种处罚做法：违规没收激活码、下级违规上级被封。我们都不做——对代理讲差异化的原话。
TSP
海外短视频电商 / 代运营服务商。一家背后 100–200 个店铺，优先级 ④。
命中画像
对方属五类客户之一，且能说出「多账号 / 设备 / 环境」的痛点。达标线：20 条私信里命中 ≥ 50%。
一队两用
同一批人跑两条漏斗：A 直销（卖窗口给大 C / 小 B）+ B 招代理（签代理、拿板卡）。
日打卡四个数
私信数 · 回复 · 有效沟通 · 加微（成交单独标记）。20:00 前交，没交 = 记 0。
一单
1 次成交，不论大小。团队内部统计的统一口径。
代理 GMV
销售部 = 渠道发展部，考核代理 GMV，不考核窗数。
环境隔离
把账号的「环境」分开：设备层（窗口）+ 网络层（独立 IP）各自独立。
指纹浏览器
客户已在用的环境隔离工具，覆盖浏览器层。它缺的正是「设备」这一层——第 ⑤ 类客户。
三项安全认证
Google Play / SafetyNet / Widevine L1。海外场景的硬门槛。
